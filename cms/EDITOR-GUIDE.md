# Widows Sons L&R — chapter editing

Sign in at `https://wsmba.the-grange.uk/wp-admin/` once DNS and trusted HTTPS are active.
Use your own Chapter editor account. The administrator can add individual editor
accounts; the supplied bootstrap account is for the site owner's initial access.

1. **Pages:** open Home, About, Rides, Charity, News, Gallery or Contact. Edit the
   text visually, preview, and select Update. Homepage sections are normal blocks.
2. **Posts:** publish chapter news. Published posts automatically appear in News
   and the homepage news section.
3. **Rides & events:** enter a title, description, start date/time and public meeting
   place in “When and where”. The chapter timezone is Europe/London. Drafts stay
   private; published future events appear automatically on the rides page and
   the public events feed.
4. **Charity stories:** add approved stories about chapter fundraising. Avoid
   publishing unconfirmed totals, beneficiary details or payment instructions.
5. **Photo albums:** use image/gallery blocks for photographs approved for sharing.
6. **Chapter enquiries:** read privately stored contact requests and use the reply
   details to follow up through the chapter's own email service. This development
   installation does not send email alerts.
7. **Appearance → Editor:** edit the shared header, footer and navigation. Revisions
   are available for recovering earlier page versions.

The editor role can publish content and edit the site design. User administration,
plugin installation and system settings belong to the site administrator. Member
records, welfare cases and ride locations are outside the public website CMS.
