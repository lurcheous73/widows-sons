The Home Proxmox host was reachable using its authorised management agent and `pct` worked. `pct status 1000` returned **configuration file does not exist**. `pct list` showed no CT1000. Therefore **nothing has been installed or launched on CT1000**; confirm where the container has been created before deployment.

## Proposed container
- ID 1000, name `widows-sons`, Debian 13, unprivileged.
- Suggested initial 2 vCPU, 4 GiB RAM and 20 GiB root disk, expandable for photos and attachments. Exact allocation depends on available host storage.
- Static/reserved LAN IP under appropriate service VLAN; do not assume an address.
- Nightly backup, periodic restore tests, logging and health monitoring.
- Keep the app isolated from Brimstone Core and The Grange services.

## Repo and compose
```sh
git clone https://github.com/lurcheous73/widows-sons.git
cd widows-sons
docker compose -f deploy/compose.yaml up --build -d
```
Demo endpoints from **within** CT1000 only: http://127.0.0.1:8080 public website mock-up; :8088 static admin preview; :8008/docs read-only sample API.

**Not for public exposure yet:** this is a static site and read-only API with no real login, tenant database, payment or safety functions. Never port-forward the prototype. Before production, implement user authentication, tenant isolation, admin MFA, security headers, audit logs, backups, TLS and reverse-proxy routing.

## Intended public routing (after hardening)
- `/` public site

All paths are one software project and one domain, with strict access controls. Do not create another standalone application for the L&R website.
