# L&R public website
A static, accessible preview in the **same repository** as backend, admin and mobile.
Open `site/index.html` directly in a browser to inspect it. No hosting or live domain is configured.
Do not publish with club insignia, real event information, payment links or contact details until the chapter approves them.
Intended production paths: `/` public website, `/members` authenticated clubhouse, `/admin` authorised administration, `/api` shared backend. This routing is **planned**, not yet implemented.
The current sample site is static and all membership/shop functions are marked as not operational.
